사용법

  1. 새 프로젝트에서 편집이 끝난 영상과 도면(층별 여러 장 가능)을 올립니다. 올리면 벽·얇은 칸막이·창·문·계단을 자동으로 인식해서 깔끔한 직선과 곡선으로 그려 둡니다(③ 도면 다듬기에서 빨간 선). 잘못 잡힌 것은 지우고 빠진 것은 도구로 그리면 됩니다.
  2. 방 찍기: 도면의 빈 곳을 클릭하면 그 자리에 방이 추가됩니다(이름 입력). 드래그로 옮기고, 우클릭하면 삭제합니다.
  3. 이동 기록: 영상을 재생하다가 방에 들어가는 순간 숫자키 1~9를 누르세요. 멈춘 상태에서 도면의 방 점이나 방 버튼을 클릭해도 됩니다. 첫 기록이 출발한 방이 됩니다.
  4. 타임라인의 ◆ 기록은 드래그해서 시각을 조정할 수 있습니다. 주황 표시는 AI가 추천한 이동 시점입니다.
  5. 미리보기를 확인한 다음 렌더링하고 overlay.mov를 Premiere 영상 위 트랙의 0초 위치에 올립니다.
