# House-Map: 부동산 영상 미니맵 생성기

부동산 내부 촬영 영상의 우측 하단에 **칠판 스타일 도면 + 현재 있는 방 표시(빛나는 마커)**를 합성합니다.
위치는 **방 단위**로 표시합니다. 방 안에서의 세부 움직임은 표시하지 않고, 방을 옮길 때 마커가 부드럽게 이동합니다.
기획, 설계, 로드맵과 확인이 필요한 사항은 [docs/PLAN.md](docs/PLAN.md)에 있습니다.

## 실행

**Windows (친구 PC 등)**: 압축을 풀고 `start.bat`을 더블클릭합니다. 처음 한 번은 자동으로 설치하고, 그 뒤로는 바로 실행되며 브라우저도 자동으로 열립니다. 자세한 내용은 `설치방법.txt`에 있습니다.

**다른 PC에 줄 zip 만들기**: `.venv/bin/python scripts/make_release.py` → `dist/house-map-날짜.zip` (내 스타일 프리셋 포함, 영상과 프로젝트는 제외)

**개발용 (WSL/Linux)**:
```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
```
브라우저에서 http://localhost:8000 에 접속합니다. FFmpeg는 `imageio-ffmpeg`에 포함되어 있어 따로 설치하지 않아도 됩니다.

## 사용 순서
1. **새 프로젝트**에서 영상과 도면 이미지를 올립니다. 복층이면 도면을 1층, 2층 순서로 여러 장 선택합니다.
2. **방 찍기**: 도면의 빈 곳을 클릭하고 방 이름을 입력합니다. 층 탭을 눌러 층을 바꿉니다.
3. **이동 기록**: 영상을 재생하다가 방에 들어가는 순간 **숫자키 1~9**를 누릅니다. 방 점이나 방 버튼을 클릭해도 됩니다.
   - 타임라인의 ◆ 기록은 드래그해서 시각을 조정할 수 있습니다.
   - "AI 이동 시점 추천"을 실행하면 멈춤과 장면 전환 시점이 표시됩니다.
4. 재생하면서 미리보기를 확인한 다음 **렌더링**을 누르고 결과를 다운로드합니다.
   - `overlay.mov` (기본): 배경이 투명한 오버레이. 편집툴에서 편집 영상 위 트랙의 0초 위치에 올립니다.
     - QuickTime Animation 코덱(기본): 2K 10분 기준 약 100MB, 렌더링 40초 안팎
     - ProRes 4444: 약 4.5GB, 약 10분
   - `minimap_1F.png` …: 층별 미니맵 도면 이미지 (1600px, 모서리 투명)
   - `composite.mp4`: 영상과 합성한 확인용 영상 (선택)

## 도면 다듬기 (가구가 그려진 컬러·렌더링 도면)
도면을 올리면 다음을 **자동으로 인식해서 벡터(직선·1/4원·사각형)로 그려 둡니다**. 픽셀을 그대로 베끼는 대신 곧은 선으로 다시 그리기 때문에 울퉁불퉁하지 않고 모서리가 깔끔하게 만납니다.
- **벽**: 어둡고 무채색인 굵은 띠를 수평·수직 직선으로. 벽끼리 이어진 것만 벽으로 보고, 방 한가운데의 짙은 가구(소파·침대)는 뺍니다.
- **얇은 선·창**: 벽과 벽 사이를 잇는 얇은 선(화장실 유리 칸막이 등)과 바깥벽이 끊긴 자리(창)를 얇은 선으로.
- **문**: 도면에 그려진 문 호(1/4원)를 찾아 경첩을 벽 위에 놓고 정확히 90°로.
- **계단**: 일정한 간격의 평행선 묶음을 계단으로.

편집 화면의 도면 카드에서 **③ 도면 다듬기**를 누르면 자동 인식 항목이 **빨간 선**, 직접 그린 것이 **파란 선**으로 보입니다. 자동 항목도 삭제(X)·옮기기(Ctrl+드래그)·뒤집기(F)가 됩니다.
1. **자동 벽 인식**을 "컬러·렌더링 도면"으로 둡니다. 인식 강도와 도구 모음의 **자동 인식** 체크(벽 / 얇은 선·창 / 문 / 계단)를 바꾼 뒤 **↻ 다시 인식**을 누르면 보고 있는 층의 자동 항목만 다시 만들어집니다(직접 그린 것과 지우개 자국은 남습니다). **자동 인식 지우기**를 누르면 자동 항목이 사라지고 예전 방식의 픽셀 벽 인식이 다시 보입니다.
2. 자동으로 안 잡히는 구조와 설비는 직접 그립니다. 변기·세면대·싱크대·인덕션·옷장은 도면마다 그림이 제각각이라 자동으로 잡지 않고 도구로 그립니다.
   - **선 (L)**: 유리 칸막이, 창 쪽 외곽선, 실 구분선. 수평·수직에 자동으로 맞춰지고 Alt를 누르면 자유 각도입니다.
   - **얇은 선 (T)**: 창, 칸막이, 바닥 단차처럼 벽보다 가는 선입니다.
   - **문 (D)**: 경첩 위치에서 문 끝까지 드래그합니다. 그려진 문을 클릭하면 여는 방향이 뒤집힙니다.
   - **계단 (S)**: 계단 영역을 사각형으로 드래그하면 디딤판 선이 자동으로 들어갑니다.
   - **변기 (B)**: 벽에 붙는 쪽 가운데에서 앞쪽으로 드래그합니다. 평평한 면이 벽 쪽에 오고, 옆면은 곧고 앞쪽만 둥근 D 모양으로 그려집니다.
   - **옮기기**: Ctrl(맥은 ⌘)을 누른 채 그린 도형을 드래그하면 통째로 옮겨집니다. Ctrl을 누르고 도형 위에 올리면 손 모양 커서가 됩니다.
   - **크기 조절 (A)**: 크기 조절 도구를 들거나 다른 도구를 든 채 Shift를 누르면 도형에 작은 네모 손잡이가 보입니다. 선·문은 끝점, 사각형·계단·설비는 모서리와 변, 원은 테두리, 변기는 벽 쪽과 앞쪽을 드래그해서 크기를 바꿉니다. 선은 수평·수직이 유지되고 Alt를 누르면 자유 각도입니다.
   - 선을 벽까지 그으면 벽을 조금 지나치거나 못 미쳐도 끝이 벽 선 위에 정확히 맞춰지고, 도면 바깥선 밖으로 나간 끝은 바깥 벽에서 잘립니다. 캔버스 밖으로 드래그해도 도면 밖에 그려지지 않습니다. 자동 인식도 창 구간에서 벽 끝이 바깥선 밖으로 삐져나오지 않게 다듬습니다.
   - 문·계단·변기는 그려진 것 위에서 드래그를 시작해도 새로 그려집니다(계단 옆에 이어서 계단을 그릴 수 있습니다). 움직이지 않고 클릭만 하면 뒤집기입니다.
   - **복사 (V)**: 복사 도구를 들고 도형을 클릭하면 바로 옆에 복사본이 생기고, 드래그하면 복사본이 그 자리로 옮겨집니다. 다른 도구를 든 채 Ctrl+Shift+드래그해도 같습니다. 자동 인식 항목을 복사하면 복사본은 직접 그린 것(파란 선)으로 취급됩니다.
   - **뒤집기 (F)**: 문·변기·계단을 클릭하면 뒤집힙니다 (문은 여는 방향, 변기는 벽 반대쪽, 계단은 단 방향). 각 도구를 든 채 그려진 도형을 클릭해도 같습니다.
   - **세면대 (W)**: 모서리에서 모서리로 드래그. 상판 사각형 안에 타원 볼이 그려집니다.
   - **싱크대 (K)**: 주방 싱크대. 상판 사각형 안에 사각 볼이 그려집니다.
   - **인덕션 (I)**: 정사각에 가까우면 화구 4개, 길쭉하면 3개가 그려집니다.
   - **옷장 (O)**: 긴 쪽으로 옷걸이 봉과 옷걸이 표시가 그려집니다.
   - **사각형 (R)**: 욕조, 기둥 등. 모서리에서 모서리로 드래그합니다.
   - **원 (C)**: 중심에서 바깥으로 드래그합니다.
   - 변기, 세면대, 싱크대, 인덕션, 옷장, 사각형, 원은 **"도형은 얇게"**가 켜져 있으면 벽의 절반 굵기로 그려집니다.
3. 잘못 잡힌 자동 항목은 **삭제 (X)**로 지우거나 **지우개 (E)**로 문지릅니다. 지우개는 그 시점까지 그려진 모든 선(자동 인식 선과 그 전에 직접 그린 것)을 실제로 지우고, 지운 뒤에 그린 것은 그대로 남습니다. 편집 화면에서도 지워진 그대로 보이고 지나간 흔적은 남지 않습니다. 삭제(X) 도구를 들면 지운 자리가 연하게 보이며, 클릭하면 그 자국이 지워져 선이 되살아납니다. `[` `]` 키로 지우개 크기를 바꿉니다. **Ctrl+Z**로 되돌립니다.
4. 방 이름은 ① 방 · 이동 기록에서 입력한 이름(예: Room, Kitchen)이 방 점 바로 위에 표시됩니다(위쪽에 자리가 없으면 아래). 도면의 빈 곳을 클릭하면 방 추가 창이 뜨고, 예시 이름(Entrance, Living Room, Kitchen, Room, Bath, Terrace …)을 누르면 입력창에 들어갑니다.
5. 배경 불투명도를 낮춰 투명하게 써도 선 주위에 그림자(후광)는 그리지 않습니다.

렌더링할 때 "도면 이미지"를 선택하면 칠판 미니맵(`minimap_1F.png`)과 **흰 배경 홍보용 미니 도면**(`plan_1F.png`)이 함께 만들어집니다.

## 방 이동 (직선 + 꺾기, 속도 조절)
미니맵 스타일 카드의 **방 이동** 항목에서 기본값을 정하고, **이동 기록 표**에서 구간마다 "걸어서 이동 / 스르르 전환"과 이동 시간(초)을 따로 정할 수 있습니다.
- **걸어서 이동**: 두 방을 직선으로 잇습니다. 벽을 가로지르면 안 되는 구간은 **② 경로 꺾기** 모드에서 꺾는 점을 찍어 주세요.
  - ② 경로 꺾기 모드로 바꾸면 보고 있는 층의 모든 이동 경로가 파란 선으로 뜹니다.
  - 선 근처를 클릭하면 가장 가까운 구간에 꺾는 점이 끼어듭니다. 점은 드래그로 옮기고 우클릭으로 지웁니다.
  - 이동 기록 표에 "↩ 꺾임 2"처럼 개수가 표시되고, 옆의 **초기화**를 누르면 묻지 않고 바로 그 구간이 직선으로 돌아갑니다.
  - 꺾는 점 추가·옮기기·삭제·초기화는 **Ctrl+Z**나 ② 모드의 **↶ 되돌리기** 버튼으로 되돌립니다.
  - 꺾은 경로가 길어지면 "속도로" 방식에서는 이동 시간도 그만큼 늘어납니다.
  - ① 방 · 이동 기록 화면의 도면에 실제 이동 경로가 **점선**으로 표시됩니다.
- **스르르 전환**: 마커가 이전 방에서 서서히 사라졌다가 다음 방에서 서서히 나타납니다("스르르 전환 시간"으로 조절). 층이 바뀌는 이동은 항상 이 방식이며, 마커가 사라진 사이에 도면이 바뀝니다.
- **도면 노출 구간 (층별)**: 도면 위 층 탭 아래에서 그 층 도면이 **나타나는 시각과 사라지는 시각**을 정합니다. "⏺ 현재"를 누르면 지금 재생 중인 시각이 들어가고, 비워 두면 영상 처음/끝까지입니다.
  - 구간을 정한 층은 그 구간 동안 마커 위치와 상관없이 도면이 보이고, 마커는 그 층에 있을 때만 나타납니다. 구간을 정하지 않은 층은 마커가 그 층에 있을 때 보입니다.
  - 어느 층 구간에도 들지 않는 시간에는 미니맵이 나오지 않습니다. 도면이 바뀌거나 사라질 때마다 "도면 스르륵 시간"만큼 서서히 넘어갑니다.
  - 도면은 한 번에 하나만 그려지므로 두 층이 동시에 보이는 일은 없습니다. 구간이 겹치면 나중에 시작한 층이 보입니다.
  - 타임라인 위쪽의 얇은 띠가 노출 구간입니다.
- **이동 시간 정하기**
  - 속도로(기본): 먼 방일수록 오래 걸립니다. "이동 속도"는 도면 끝에서 끝까지 걷는 시간(초)이며, 슬라이더를 오른쪽으로 옮길수록 빨라집니다.
  - 모든 이동 같은 시간: 이동마다 정한 시간(초)만큼 걸립니다.
- **기록한 시점은**: 숫자키를 누른 순간이 이동 시작 / 한가운데 / 도착 중 어디인지 정합니다.
- 이동 기록 표에 이동마다 걸리는 시간이 표시됩니다. 앞 이동이 안 끝나서 늦게 출발하거나 영상 안에 도착하지 못하면 **⚠**로 알려줍니다.

## Premiere Pro에 넣는 방법
1. `overlay.mov`를 가져와서 편집 영상 위 트랙(V2)의 **00:00:00:00** 위치에 놓습니다. 영상과 길이가 똑같이 끝납니다.
2. 오버레이를 만들 때 업로드한 영상은 **최종 편집본을 내보낸 파일**이어야 합니다. 그 뒤에 컷을 수정하면 이동 기록을 다시 맞추고 오버레이를 다시 렌더링해야 합니다.
3. 미니맵 가장자리에 검은 테두리나 어두운 번짐이 보이면, 클립을 우클릭하고 **수정 → 푸티지 해석 → 알파 채널**에서 "알파를 곧게 유지(Straight)"로 설정합니다.
4. 층별로 오버레이를 따로 만들었다면 각 오버레이를 해당 층 구간에 놓고 앞뒤를 잘라내면 됩니다. 같은 프리셋을 썼다면 위치와 크기가 똑같습니다.

## 미니맵 스타일
- **선 굵기 통일**: 켜면 도면마다 달라지는 선 굵기가 같아집니다. 벽 인식 방식은 "도면 다듬기" 도구 모음에서 고릅니다.
- **도면 영역 자동 맞춤**: 인식된 구조에 맞춰 영역을 잘라서 "A-2 (1st Floor)" 같은 제목 띠와 여백을 뺍니다.
- **방 이름**: 방 목록에 입력한 이름이 마커 위치 아래에 손글씨로 표시됩니다.
- **일관성**:
  - 도면 영역 비율(기본 0.8)이 고정되어 있어서 어떤 도면을 넣어도 미니맵 크기와 위치가 같습니다.
  - 스타일을 **프리셋**으로 저장해 두고 새 프로젝트를 만들 때 선택하면 모든 매물과 층에 같은 디자인이 적용됩니다.
- **칠판**(기본): 도면에서 어두운 선만 뽑아 분필 선으로 다시 그립니다. 컬러 바닥재나 가구 채색은 "선 인식 강도"로 걸러냅니다.
- **원본**: 올린 도면 이미지를 그대로 씁니다. 이미 디자인된 미니맵 이미지를 가지고 있을 때 선택합니다.
- 제목(기본값: "{매물 이름} mini map"), 층 표시(1F/2F), 하단 안내문, 배경·선·마커 색, 빛 번짐, 이동 효과, 위치와 크기를 설정할 수 있습니다.
- 브라우저 미리보기는 서버가 그린 패널 이미지를 그대로 쓰기 때문에 최종 렌더링 결과와 똑같습니다.

## 구조
| 파일 | 역할 |
|---|---|
| `app/main.py` | FastAPI 서버: 프로젝트, 층, 방, 이동 기록, 작업 큐, 다운로드 |
| `app/track.py` | 방 이동 기록을 프레임별 (층, x, y)로 변환 (이동 구간은 부드럽게, 층 전환은 즉시) |
| `app/render.py` | 칠판 미니맵 생성(선 추출, 분필 질감, 손글씨 제목), 마커 스프라이트, FFmpeg 인코딩 |
| `app/vectorize.py` | 업로드한 도면에서 벽·얇은 선·창·문·계단을 벡터 편집 항목으로 자동 인식 |
| `app/motion.py` | OpenCV 광학 흐름으로 걷기·멈춤·장면 전환을 분석해 이동 시점 추천 |
| `static/` | 웹 UI (Vanilla JS) + 폰트 |
